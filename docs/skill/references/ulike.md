# Ulike：消费品牌的排障与服务中心

识别名：Ulike、helpcenter.ulike.com。用户说“做一个跟 Ulike 一样的帮助中心”时读取本例，并结合 `docs/skill/references/design-playbook.md`。设计来源截至 2026-10-19，不代表客户要使用 Ulike 的品牌或业务资料。

## 实际观察

- [首页](https://helpcenter.ulike.com/)：白色品牌页头，Logo、产品/排障与品牌站导航、账户和搜索；浅灰横幅左文案、搜索与浅粉热门搜索胶囊，右客服人物照片。加载完成后有人物图，不能把图片加载前的留白当设计。
- 首页依次是产品排障入口（四类产品图）、FAQ 折叠问题、六组服务主题卡（主题、若干子链接、数量）、聊天/邮件/电话渠道，再到品牌站页脚。白底、大留白、黑色标题、浅粉强调和轻分隔构成品牌感。
- [产品排障分类](https://helpcenter.ulike.com/trouble_shooting/50934)：顶部产品组合大横幅，下面按开始使用、使用过程、使用后、维护等阶段分组。每组以问题卡呈现标题、短说明和进入动作，末尾继续搜索及支持指引。它不是普通的产品图片墙。
- [排障文章](https://helpcenter.ulike.com/trouble_shooting/50934/b72d5/c5c41)：面包屑、左层级目录、文章标题/日期/灰底粉边摘要，正文按适用型号、原因、排查步骤组织；还出现 Most Viewed 与右 TOC，文末有联系渠道、前后篇和反馈。1280 宽下多个辅助栏挤压正文，不应盲目复制四列。
- 390 宽实看：页头折叠导航/搜索，文章有目录按钮、窄屏正文。首页人物图裁切后与文字重叠，热门搜索隐藏；新版应优化裁切和对比度，而不是复制这个问题。

本次截图证据在应用仓库 `tmp/help-customer-design-20261019/screenshots/ulike-*.jpg`；截图仅供本地研究，不是新站素材。网站会变化，后续精确还原需要重新查看原站。

## 可复用设计处方

适用于品牌消费品、美容设备、家电等“使用问题 + 购买服务”并重的支持中心；核心是把产品排障、短答案、服务政策和人工渠道串起来。若客户只有一个简单手册或没有产品图片，不强行填满这些区块。

推荐顺序：品牌页头 → 左文右图的搜索 Hero → 产品排障带 → 高频问答 → 主题卡 → 真实联系渠道。标题与内容用客户语言；保留留白和温和强调色，色值、图片、字体以客户品牌为准。没有正式人物素材时采用纯色/轻背景搜索首屏。

内页以目录 + 正文 + TOC 三列为目标；热门内容放文末，分类按用户经历的阶段分组，文章突出适用产品与操作步骤。手机用单列正文、折叠目录，联系渠道堆叠，不让浮动聊天遮挡正文。

## 新版 Help 落地

- 配置起点：`index_style=help_center`（`index.help_center` 变体），`article_layout=tree`、`category_layout=list`；客户要求自动搭配时改为 `auto/auto`（该变体派生 reader + cards），并说明与参考站目录阅读的差异。不能看到产品图就忽略搜索和服务主题。
- 可直接写：客户品牌、Logo、首页 hero 与正式 DAM hero_image、精选真实文章、FAQ 分类路径、已有支持链接。已有 hero_image 时，基础模板即支持左文右图，但图片呈现在独立圆角卡片中。日期显示是客户偏好，不从参考日期复制。
- 需要候选：人物融入整幅横幅的视觉、品牌比例与留白、独立产品带与服务主题的双分区、FAQ 在主题前、帮助中心变体内增加主题子链接、阶段分组的问题卡、品牌导航和页脚、多级树。三个首页变体都不内置这套完整组合。
- 需要实际页面素材/设置：产品卡图、摘要、指定关联文章等普通页展示字段；当前 Agent 的 `seed_content` 不支持写这些 fields。先组织真实知识内容，再在页面设置补齐，不能硬编码案例商品或虚报完成。
- 核对默认能力：当前 Hero 快捷链接指向分类，不是热门搜索；非产品主题卡在有可访问子页时已显示数量，`index.help_center` 变体直接展示最多三个子链接。`tree` 已有上下文目录，但不是 Ulike 的完整递归树；TOC 根据正文标题生成，空文章不会出现目录。配置完成不代表这些资料已经存在。
- 搜索热词和“订单查询”只有存在真实目标时才做链接；购物账户、在线聊天等须接客户自己的系统。不要复制 Ulike 的电话、时段、退换货政策或护理建议。

## 需求示例与验收

输入：“我们做家用美容仪，想要 Ulike 那样的支持中心，产品排障、订单售后都要方便找。”

应输出：“用搜索首屏、产品排障、FAQ、服务主题和联系渠道组织首页；文章保留目录与页内导航。使用你的品牌图和真实政策，缺少的素材在页面设置补齐。”接着读取资料、配置基础站与制作必要候选，不把“像 Ulike”写成知识文章。

验收至少检查产品入口 → 阶段分类 → 排障正文，FAQ 展开/继续阅读、主题到文章、真实支持渠道、390 宽导航与图片裁切。若只完成基础配置，明确说出尚未完成的品牌组合区块。
