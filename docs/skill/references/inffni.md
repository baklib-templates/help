# INFFNI：少量明确任务与场景化入口

观察日期：2026-10-19。来源为官方支持站页面文本与同日桌面浏览器验收；未找到明确对应的本地客户主题。本次截图索引：`tmp/help-customer-design-20261019/screenshots/` 下的 `inffni-home.jpg`、`inffni-quick-start.jpg`、`inffni-faq.jpg`。

## 已观察的界面与页面链

[首页](https://support.inffnitech.com/)使用白色简洁页头，左侧品牌标志，右侧搜索和主题按钮。大幅生活场景照片作为主视觉，叠加暗色遮罩、居中白色标题及白色胶囊搜索框。服务区为浅灰蓝背景，横排四张白色小卡，搭配蓝色线图标和标题旁蓝色竖线；后面是视频缩略图网格。

四个入口直接对应任务正文，不要求用户先选择产品：

- [售后服务](https://support.inffnitech.com/15b4d)：退换货、保修、运输等政策正文。
- [FAQ](https://support.inffnitech.com/924d0)：按选购、规格、控制、使用、维护、隐私等主题编排的长正文。浏览器确认是多级标题内容，不是逐题折叠集合。
- [快速开始](https://support.inffnitech.com/9ba40)：摘要、两份 PDF 附件及 App 下载说明。
- [App 下载](https://support.inffnitech.com/6ce3a)：下载说明与二维码；另有[视频课程页](https://support.inffnitech.com/98852)。

内页是左侧四任务导航、中间正文、右侧浅灰页内目录。导航以蓝色标出当前项，大标题左侧有蓝色竖线，摘要放在灰底区域，附件用卡片表示。这里的侧导航是任务间导航，右侧目录才是当前文章的章节导航。

## 可复用处方

适合产品线较集中、主要需求可以归纳为几个明确任务的品牌。以“开始使用、找答案、获取应用、处理售后”提供直达入口；场景照片交代产品用途，搜索负责承接更具体的问题。短入口和长正文可以共存，不必把所有内容拆成独立问题页。

可借鉴大图上的搜索、有限任务卡、摘要和附件呈现。使用客户自己的场景图、品牌色、手册和下载地址，不复制案例的政策条款、二维码或产品事实。

## 现有 Help 配置与候选定制边界

| 需求 | 现有能力与实施边界 |
| --- | --- |
| 搜索优先、任务直达 | 统一选 `index.help_center` 变体；三个变体都有搜索，不因页面有搜索框就忽略客户真正的访问顺序。四任务可作为真实一级知识分类或内容页。客户明确要求短答案成为首页主体时才改选 `index.faqs`。 |
| 左任务导航＋正文＋右目录 | `index.help_center` 的 `article_layout=auto` 派生 `reader`；客户明确要求三栏阅读时显式设 `article_layout=tree`，已有页内目录基础。 |
| 场景背景图、遮罩、胶囊搜索 | 现有 `hero_image` 是横幅内独立图片区域，并非铺满背景。案例中的大图背景、遮罩、搜索样式和蓝色装饰需要组织候选定制；有图片字段不代表已有该版式。 |
| 长 FAQ | 保留原文标题层级和页内目录，使用普通文章阅读。当前 `index.faqs` 变体从真实子页生成问题集合，不会自动把一篇正文的标题拆成问答，也不应因为页面名叫 FAQ 就强制切换。 |
| 附件卡、App 二维码、视频网格 | 需客户提供实际文件、图片、视频或已有正文引用。已有来源内容可按平台同步；当前 Agent 不能据截图生成文件、上传媒体或承诺制作好下载卡和视频集合。专用首页视频区需候选定制。 |
| 普通页摘要与展示字段 | `description`、`icon_image`、`icon_name`、`reading_layout`、`tags`、`video_url`、`related_pages` 在页面设置中编辑，当前 `seed_content` 不写这些普通页字段。灰底摘要和附件卡的具体样式也需按真实内容验收。 |

基础品牌、首页标题与说明、精选真实路径可用现有设置。不要为四张任务卡额外复制旧模板或造一套内容模型；先形成真实页面链，再在候选中调整视觉与模块。客服地址、服务时间和政策只能来自客户确认的资料。

## 移动适配建议（本次未实测）

- 场景图重新选择裁切焦点，保证文字对比度；搜索占满可用宽度，避免胶囊框挤压输入区域。
- 四任务卡改为两列或一列，图标和文字同时可点击；视频缩略图保持固定比例。
- 三栏合并为单列：任务导航可展开，页内目录置于正文之前并可收起。
- 长 FAQ 保留标题锚点和返回目录入口；不为节省高度把整篇内容改成大量默认收起的问题。
- 附件卡展示真实名称与可取得的文件信息，长文件名换行；二维码之外提供客户确认的直接链接。

## 适用范围与命名需求示例

适用于单一主产品、少量产品系列和清晰售后任务。型号很多、型号之间安装方法差异显著时，应优先产品范围导航；不宜把大量型号塞进四张笼统任务卡。

客户说“参考 INFFNI，大场景图，四个入口就能找到答案，内页有左右目录”时，提取为“场景化搜索首页＋少量任务直达＋三栏长文阅读”。先用真实任务建立基础站点，再候选定制背景图和任务区。客户若点名“FAQ 也像它”，保留长文与目录，不误解为折叠问答首页。
